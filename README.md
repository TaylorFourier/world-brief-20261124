A deterministic offline program that draws a one-page world brief of Tuesday 24 November 2026 and writes it to `/output/entry.png`. The Strait of Hormuz item is drawn as an IRGC claim and labeled not independently confirmed.

## Run it

```sh
python3 main.py
```

The command needs no network and no installed packages. It reads the Liberation fonts bundled in `fonts/` and writes a 1024×1024 PNG. Those fonts stay under the SIL Open Font License in `fonts/OFL.txt`. The program itself is MIT.
